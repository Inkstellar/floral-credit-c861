/ 02 Workflow

Consumption Guide

InkBuddy reduces the friction of design handover. Instead of static docs, it provides a command-line interface to generate the actual implementation.

1

Initialize Styles

Run setup to inject the design system's CSS tokens.

2

Generate Primitive

Use generate --type=button to scaffold a component.

3

Deploy & Scale

Components ship with built-in accessibility and token bindings.

$ inkbuddy setup
✅ Design system styles injected...
$ inkbuddy generate --type=button --variant=primary
Generating Component...
✅ src/components/button/Button.tsx created
$ inkbuddy list
• button: @radix-ui/react-button
• input: @radix-ui/react-textfield

/ 03 Integration

MCP Server Availability

InkBuddy implements the Model Context Protocol, enabling AI agents to autonomously manage your design system.

  • AI can list_templates to understand system capabilities.
  • AI can generate_component via natural language prompts.
  • Automated setup_design_system routines.
